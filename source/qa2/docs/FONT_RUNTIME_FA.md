# قرارداد تایپوگرافی فارسی Sokna House

- فونت اصلی رابط: **Vazirmatn Variable v33.003**
- خانواده فونت یک Token رسمی سیستم طراحی است: `--font-ui`.
- تعریف `@font-face` در Base انجام می‌شود؛ لایه CSS جدیدی ساخته نمی‌شود. چون Base داخل `assets/app.css` compile می‌شود، قرارداد مسیر باید هم محل source (`assets/css/base.css`) و هم محل bundle (`assets/app.css`) را پوشش دهد؛ در dev19 دو candidate نسبی به‌ترتیب bundle/source تعریف شده‌اند تا هر دو به `font.php` همان subfolder نصب برسند.
- فیش و برگه چاپی نیز از همان خانواده استفاده می‌کنند.
- فایل باینری داخل Release قرار نمی‌گیرد.
- منبع نخست: jsDelivr روی Tag رسمی `v33.003`.
- منبع دوم: مخزن رسمی GitHub روی همان Tag.
- ذخیره محلی: `assets/fonts/Vazirmatn-Variable.woff2`.
- اعتبارسنجی: WOFF2 magic + محدودیت اندازه.
- نوشتن: فایل موقت + rename اتمیک.
- مدیر مشترک: `app/FontManager.php`؛ `font.php` فقط Endpoint سرو فونت است.
- دریافت خودکار هنگام درخواست فونت فقط از cURL استفاده می‌کند تا صفحه روی DNS/Stream کند معطل نشود. اگر cURL موجود نباشد، رابط فوراً با فونت جایگزین نمایش داده می‌شود. Stream امن فقط در نصب اولیه یا تلاش دستی مدیر استفاده می‌شود. در مسیر cURL همه منابع یک بودجه زمانی کل مشترک دارند.
- TLS در هر دو مسیر اعتبارسنجی می‌شود.
- شکست دانلود: fallback سیستمی و تلاش مجدد حداکثر هر ۶ ساعت.
- نصب تمیز یک تلاش کوتاه برای Warm-up Cache انجام می‌دهد؛ شکست فونت باعث شکست نصب سامانه نمی‌شود.
- صفحه «وضعیت سامانه» وضعیت فونت را با زبان مدیریتی نمایش می‌دهد. مدیر می‌تواند دریافت خودکار را دوباره امتحان کند یا فایل معتبر Vazirmatn Variable WOFF2 را از دستگاه خود روی همان سرور نصب کند. مسیر Upload با همان Magic/Size Validation بررسی می‌شود.
- فایل باینری فونت داخل Release توزیع نمی‌شود؛ مسیر دستی فقط برای نصب Local روی سرور موجود است.
- مقادیر فنی لاتین طبق قرارداد Bidi/LTR موجود ایزوله می‌مانند.


## کنترل توسعه

```bash
php tools/font_runtime_contract_check.php
```

این تست بدون دریافت فایل فونت از اینترنت، اعتبارسنجی WOFF2، نسخه پین‌شده، مسیرهای cURL/Stream، TLS، نوشتن اتمیک، Endpoint، Warm-up نصب، Health UI و مسیر نصب دستی روی همان سرور را کنترل می‌کند. فایل باینری فونت داخل Release قرار نمی‌گیرد.
