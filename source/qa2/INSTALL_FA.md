# نصب تمیز 2.6.19-dev.25-qa2 — فقط Staging

این کاندید هیچ مجوزی برای استفاده Production ندارد. نسخه اپلیکیشن: `2.6.19-dev.25-qa2`؛ نسخه ساختار داده: `2.6.0-rc7-qa1`؛ به‌دلیل جدول جدید مالی، Update نسبت به dev24 نیازمند Migration است و منتشر نشده.

۱. سایت و دیتابیس آزمایشیِ جدا و خالی، با HTTPS آماده کنید. ۲. PHP 8.1+ و `pdo_mysql`, `mbstring`, `zip`, `json` و InnoDB/utf8mb4 را فعال کنید. ۳. فایل CLEAN را در ریشه سایت آزمایشی Extract کنید. ۴. مجوزهای نوشتن محدود را برای `config/`, `storage/`, `uploads/` برقرار کنید. ۵. در Staging به `install.php` بروید و با پیشوند خالی و مدیر آزمایشی نصب کنید. ۶. تست رزرو، پرداخت، گزارش، Backup/Restore و صفحه‌های اصلی را اجرا کنید. ۷. Update از dev24 فعلاً مسدود است؛ فقط بعد از تکمیل تست MariaDB و Migration اجازه اجرا دارد.

در نصب خطا یا نقص، همان محیط آزمایشی را با Backup مستقل بازیابی کنید؛ از Rollback موفقِ خودکار برای برگرداندن داده‌های تازه استفاده نکنید. قبل از نصب و بعد از آن، محتوای فایل‌ها را با `CHECKSUMS.sha256` و گزارش آزمون تطبیق دهید.

این کاندید علاوه بر اصلاحات قبلی، کنترل سلامت جدول مالی و ایندکس یکتای توکن را پیش از پذیرش Update بررسی می‌کند. MariaDB واقعی هنوز آزمایش نشده است.
